AADS Blast - PWA package
1. Upload ALL files (index.html, manifest.json, sw.js, icons/) to any HTTPS host (GitHub Pages, Netlify, Cloudflare Pages).
2. Open the hosted URL in Chrome -> you should get an "Install app" option.
3. Go to pwabuilder.com, paste your URL, choose Android, and download the package (.aab) for Google Play.
4. Upload the .aab in Google Play Console (Games category). Add a privacy policy URL (see privacy-policy.html).
